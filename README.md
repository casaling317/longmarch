# 长征：从烽火到星辰

> 副标题：一场跨越 90 年的交互式远征
> 创作方向：数智交互 ｜ 历史回望【险阻解码】
> 2026 中国人民大学附属中学联合学校总校 AI 创作者大赛 · 数智交互赛道

---

## 一、运行说明

本作品为**纯前端**响应式网页，无需后端、无需注册登录、不收集任何个人信息。

**方式 A：直接打开（推荐）**
1. 解压离线包；
2. 双击 `index.html`，用现代浏览器（Chrome / Edge / Safari）打开即可。

**方式 B：本地服务器（可选）**
```bash
# 在 longmarch 目录下
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

**适配**：优先适配手机竖屏，同时适配桌面端。建议屏幕宽度 ≥ 360px。

## 三、游戏规则 / 交互说明

- 全程**无“正确 / 错误”判定**。用户的选择用于**理解历史处境**，不用于预测或篡改真实历史。
- 玩家选择只影响**体验路径与理解方式**（路线脉冲、节点亮暗、行囊状态、揭示顺序），不伪造历史结果。
- 《险阻》一关：四选三。选满 3 件显示“你的行囊”状态行；尝试选第 4 件时行囊抖动并提示"点一件已选的换掉它"。
- 《湘江》一关：沉浸式历史场景。湘江战役大地图（示意视觉，非精确地理）+ 四个模块：**时间线**（每点一次路线推进一步、日期同步，第 2 步起 5 座渡口点亮）、**地形**（地图放大，显示河流 / 渡口 / 行军方向）、**史料**（大幅 AI 艺术再现图 + 简短说明）、**人物**（第三十四师的故事）。每次点击都在地图 / 图版上产生可见变化，**再点一次即取消、可重新体验**；四个模块全部点亮触发视觉高潮（三十四师标记闪红 + 地图抖动 + 背景光线汇聚），随后进入"史实解码"，展示经核验的真实史实。配克制的江水声氛围音（Web Audio 实时合成）。
- 《转折》一关：先让玩家选择"首先会考虑什么"（怎么打 / 谁来定 / 往哪走，3 个方向，均非知识考试）。选择后：即时反馈文案 + 背景地图出现对应标记（战斗 X / 决策圆环 / 方向箭头）+ 红色路线从湘江真正推进到遵义、抵达时遵义节点点亮；之后再揭示"历史最终走向了这里"并展示遵义会议史实。
- 《30 秒 · 历史现场重现》一关：30 秒内 2 个"瞬间"——瞬间1"怎么走"（镜像湘江渡口处境）、瞬间2"怎么选"（镜像遵义方向抉择），每瞬间 3 选 1、**可换选**（不锁死、不置灰，取最后选择）；选择后即时反馈 + 一句历史回声。结尾升华块按你的实际所选**动态组装**"历史里，你的这两个选择，各有各的分量——……"，并以桥接句"烽火里的每一个选择，都会走到星辰里"铰链到下一幕。配低音量环境氛围音（Web Audio 实时合成）。
- 《星辰》一关（S0–S3 状态机，同一场景内切换、不加新页面）：
  - **S0 时空转场**：背景数字化 + 3 行文案错峰淡入，"进入 →"由用户点击进入（无自动跳转）。
  - **S1 选择方向**：曲线从湘江/遵义画到"现在"（屏幕正中央）→ 4 组科技关键词按时代从小到大、带光晕依次浮现再渐出 → 弹窗"下一段路，你要走向哪里？"4 方向（探索未知 / 解决真实问题 / 创造新的可能 / 让技术更有温度，均为可能性、非标准答案）；选哪个→那条数字路径真实延伸 + 点亮对应星球（带椭圆轨道环 + 运行小卫星），其余淡出 + 一句预写回应 + "这一次，路线由你决定"。
  - **S2 一个词**：弹窗输入"送给下一个 90 年的一个词"（10 字以内、可不填）；填→词沿圆轨道环绕点亮星球 + 按关键词匹配一句回应；不填→直接收束。
  - **S3 收束**：光点沿"湘江→遵义→分叉→你的星辰"完整路径收拢，压暗后浮现结束卡"下一段路，轮到我们了。"+【再走一次】【查看史实与来源】。
  - 回应均为**预写文案 + 关键词匹配**（非真实 AI 调用，保持离线 / 无依赖）。

## 四、科学依据 / 史实核验说明

> **本作品中的历史事件、时间、地点、人物及相关资料均依据公开可靠史料核验；部分数值化指标为帮助理解历史条件而设置的模拟变量，并非对历史真实数据的还原。**

- 所有历史事实集中配置于 `js/content.js`，每条含 `text`、`source`（来源）、`where`（出现位置）、`verified`（核验状态）字段。
- 全部 **21 条史实**均已逐条对照权威来源核验，`verified: true`；作品内「史实与来源」页 A/B 区完整列出"事实 → 来源 → 出现位置"（A 区历史 11 条 + B 区现代科技 10 条）。
- 核验来源：
  - **湘江战役**：中央党史和文献研究院《湘江突围：长征中最为惨烈的战役》；国防部网站《血战湘江：红军长征中最惨烈之战》；求是网《事关中国革命生死存亡的湘江战役》；人民网党史频道；新华网
  - **遵义会议**：人民网·中国共产党新闻网《中国共产党大事记·1935 年》；人民网党史频道《开启党独立自主解决中国革命问题新阶段》
  - **两弹一星**：国防部网站《壮丽 70 年·奋斗新时代》；国家国防科技工业局
  - **杂交水稻**：人民日报；央视网
  - **神舟五号**：中国载人航天工程官网（cmse.gov.cn）；央广网
  - **嫦娥一号**：国家航天局；央视网
  - **蛟龙号**：央视网；新华网
  - **墨子号**：中国科学院；国家航天局
  - **北斗导航**：中国政府网；北斗卫星导航系统官网（beidou.gov.cn）
  - **天问一号**：中国政府网；国家航天局
  - **天宫空间站**：新华网；中国载人航天工程官网（cmse.gov.cn）
- **科技关键词口径**：星辰幕浮现的"国家科技发展关键词"为叙事背景 / 艺术表达；其中可压实为具体事实的（两弹一星、杂交水稻、神舟五号、嫦娥一号、蛟龙、墨子号、北斗、天问、天宫）已逐条核验并列入 B 区事实卡，"人工智能"为宽泛概念，未单独压成事实卡（来源页 B 区已说明）。
- **日期口径说明**：湘江战役起止日期在权威资料中存在口径差异（11 月 25 日—12 月 1 日，或以 11 月 27 日实际渡江战斗为起点）。本作品主视觉采用 11 月 25 日—12 月 1 日，并在湘江幕"史实解码"区附简洁说明。
- **"8.6 万余人 → 3 万余人"** 为人数锐减（含伤亡、掉队、伤病等），非单纯伤亡统计；作品文案已按此口径表述。

## 五、技术说明

- 纯 HTML / CSS / JavaScript，无框架、无构建、无外部依赖，可离线运行。
- 视觉演变：纸张 → 地图 → 数据 → 星辰（CSS 变量 + SVG 驱动）。
- 代码结构：
  - `index.html`：六幕页面骨架 + 来源页
  - `css/style.css`：视觉主题与响应式
  - `js/content.js`：唯一数据源（文案 + 史实 + source）
  - `js/app.js`：场景管理 / 交互 / 30 秒现场 / 星辰 S0–S3 状态机 / 转场 / 返回重玩
  - `js/audio.js`：Web Audio 氛围音

## 六、AI 使用说明（创作手记）

> 本作品在创作过程中使用了 AI 辅助，按比赛要求如实说明工具与使用范围。

- **使用工具**：AI 编程助手 WorkBuddy（CodeBuddy，大语言模型驱动）
- **使用范围**：
  - 代码结构与交互逻辑（场景状态机、行囊交互、30 秒现场计时、星辰 S0–S3 状态机、烽火→星辰转场）
  - 文案润色（六幕叙事文案）
  - 视觉与动效建议（CSS/SVG 视觉主题、动效实现）
  - 史实来源检索与整理辅助（最终核验由创作者完成）
- **人工核验**：所有史实由创作者对照可靠来源逐条人工核验（详见第四节），AI 生成内容不作为史实依据；未使用 AI 编造任何数据、引语或来源。
- **AI 生成图片**：3 张历史场景图（湘江强渡、第三十四师、英雄牺牲），为艺术再现、非历史照片，作品内已诚实标注（详见「史实与来源」页 C 区）；其余视觉由 CSS/SVG 程序化生成。
- **声音素材**：氛围音与牺牲时刻重击由 Web Audio 实时合成（风声 / 脚步 / 呼吸 / 水声 / 低频重击）；牺牲时刻配乐为从网络下载的悲壮管弦乐（cyberwave-orchestra-dramatic.mp3），来源与授权确认后在「史实与来源」页 C 区署名。
